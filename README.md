# DILLO project website

Static project page for **DILLO — Describe-Then-Act**, inspired by the structure of the BiCICLe project page.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

The qualitative gallery contains LIBERO rollout videos generated from the released dataset and a freshly reproduced baseline/DILLO steering comparison using the released Gemma-3 1B checkpoint.
